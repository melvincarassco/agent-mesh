# Scripts Directory (`scripts/`)

Helper scripts for project scaffolding, architectural validation, local development setup, and deployment management.

## Available Scripts

- **`bootstrap_project.py`**: Automated generator for creating new Carassco Labs projects from `agent-mesh`.
- **`setup.sh`**: Initializes local Python virtual environment, git hooks, and `.env` configuration.
- **`validate.sh`**: Runs project linting, schema validation, and handbook architecture compliance checks.
- **`deploy.sh`**: Helper shell script for deploying to Cloud Run via gcloud CLI (used for local testing).
