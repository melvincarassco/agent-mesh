# Implementation Reference Examples (`examples/`)

Contains golden standard design pattern examples for service classes, API endpoints, Pydantic schemas, and GCP SDK invocations.

## Reference Examples

- **`sample_endpoint.py`**: FastAPI controller pattern with Pydantic schemas, dependency injection, and RFC 7807 error responses.
- **`sample_service.py`**: Async domain service implementation pattern.
- **`sample_event.py`**: GCP Pub/Sub CloudEvent payload specification.
